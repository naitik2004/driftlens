# Implementation status

The architecture's MVP now has an executable Python package, CLI and advisory
GitHub integration. The supplied architecture and hackathon draft were preserved.

## Implemented

- Immutable merge-base/head snapshots, complete relevant source/docs, rename
  mappings, commit identity and diff hunks.
- AST fact extraction and bounded constant/import resolution without executing
  analyzed code.
- Source-mapped Markdown sentences/tables, old/current alignment and scoped exact
  linking.
- Before/after checks for defaults, removed parameters/flags and a constrained
  retry-count pattern, with conservative exclusions.
- Structured JSON, grouped Markdown summaries, safe annotations, pinned links,
  deterministic finding IDs and correction suggestions.
- Optional Ollama JSON-schema integration and content/model/prompt-versioned cache.
- Historical replay harness that reads later corrections only after detection.
- Reproducible synthetic demos, regression tests, packaging, CI, MIT license and
  a PR template.

## Explicit MVP limits

The first linker requires exact scope references. It follows simple constants,
not arbitrary wrappers/callers or runtime aliases. General configuration-key
changes, embeddings and additional languages remain future extensions. Claims
with unresolved scope or runtime behavior are not promoted into findings.

The initial 49-test result above is historical. The live AI integration work adds
separate harness/control and response-evidence tests. The local AI guide records
reproduction steps and explicitly distinguishes mocked unit tests from actual
inference. No model server or weights are required for ordinary CI.
